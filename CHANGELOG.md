# Changelog

## 0.1.0 — 2026-09-26

Initial public release.

- Browser-side OpenAPI search with configurable vocabulary, typo tolerance, and navigation into Swagger UI.
- Standalone Swagger UI distribution and a plugin for existing documentation pages.
- Multi-document search and an optional OpenRouter assistant that answers using retrieved API fragments.
- Six configurable free default models, ordered fallbacks, and separate handling of provider and account rate limits.
- Memory-only API keys by default, with optional host-enabled URL or local storage choices.
- ESM, CommonJS, TypeScript declarations, browser scripts, and styles.

Swagger UI 5.33.0 is the tested integration. AI answers depend on model availability and the supplied specification; automatic cross-language retrieval and externally fetched references are outside the initial scope. See README.md for compatibility and configuration.
